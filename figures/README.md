# Historical simulation figures

These figures are retained from the original simulation work. They are useful
for inspecting the model outputs and reference-tracking transients, but are
not a new benchmark or validation campaign. Re-run the model and export a
consistent figure set before quoting quantitative performance values.

- `platform_vs_quadrotor_trajectory.png`: 3-D platform and vehicle paths.
- `quadrotor_trajectory.png`: vehicle trajectory visualisation.
- `x_position_tracking.png`, `y_position_tracking.png`, and
  `z_position_tracking.png`: axis-wise reference and vehicle responses.
